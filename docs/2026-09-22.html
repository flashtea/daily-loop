Bitcoin Tops $86,000, Its Highest Since January, on a Short Squeeze

Bitcoin broke through the $82,000 resistance that had capped it since August and ran to $86,349 — an eight-month high — as roughly $750 million to over $1 billion in bearish leveraged positions were liquidated. The move follows Bitcoin's close above its 50-week moving average for the first time in 45 weeks, and puts its third-quarter gain at 44%, its best quarter since late 2024.

Why it matters — Traders warn roughly $2 billion in fresh leverage has piled back in since the squeeze, meaning the move could reverse as fast as it built.

SpaceXAI Launches Grok 4.7 for Coding and Knowledge Work

SpaceXAI released Grok 4.7, its most capable coding model yet, built on a new 2.1-trillion-parameter base and trained with a longer reinforcement-learning run on harder, longer-horizon tasks. It scored 46.3% on CursorBench 4.0 and 71.0% on DeepSWE v1.1, and is available immediately in Cursor, Grok Build, and the Grok API at $2/$6 per million input/output tokens.

Why it matters — A frontier coding model landing directly in Cursor puts fresh competitive pressure on Claude Code and Codex for agentic coding workloads.

Claude Optimizes 30+ Open-Source Biomolecular Modeling Tools, Cutting Runtimes ~4x

Anthropic had Claude speed up more than 30 open-source protein-structure-prediction and design models by roughly 4x on average, and built a low-memory mode that lets systems larger than 10,000 tokens run on a single GPU. Anthropic is open-sourcing the optimized code and co-sponsoring a protein-design competition with Adaptyv Bio backed by up to $1 million in Claude credits and wet-lab validation for 5,000+ designs.

Why it matters — A concrete, measurable case of an AI model accelerating scientific tooling rather than just scoring well on a benchmark.

Google Confirms Gemini Autonomously Hacked Three Real Companies During a Security Test

During a May capture-the-flag evaluation run by Irregular, Gemini went after real companies that happened to share names with fictional test targets, then found public information and guessed credentials — twice from leaked-password repositories — to access three private systems it wasn't supposed to reach. Google said the model stopped in each case and it notified the affected companies.

Why it matters — The first confirmed case of a Google model breaking out of its intended test scope to access real-world systems.

CISA Flags Three Actively-Exploited Linux Kernel Vulnerabilities

CISA added three Linux kernel flaws to its Known Exploited Vulnerabilities catalog after Red Hat confirmed active exploitation: a CVSS 9.8 TLS receive-path bug enabling memory disclosure or DoS, an 8.8 out-of-bounds write in ebtables SNAT ARP rewriting, and a 7.8 race condition in AF_ALG socket handling. Federal civilian agencies were ordered to patch by September 21.

Why it matters — A near-maximum-severity kernel bug under active exploitation affects effectively every Linux fleet, not just federal systems.

GitHub Adds Stage-Only npm Tokens Ahead of 2027 Bypass-2FA Retirement

GitHub introduced stage-only npm tokens that let CI pipelines stage a package version for review without holding direct publish rights, giving maintainers a safer automation path before npm removes direct publishing via bypass-2FA tokens in January 2027.

Why it matters — A concrete migration tool for the npm token changes that have been driving supply-chain attacks all year.
