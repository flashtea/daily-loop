Amazon CEO Andy Jassy called the White House the night before the Fable 5 export ban — models enter day four offline

Amazon security researchers identified what they described as a dangerous exploit in Claude Fable 5 and briefed CEO Andy Jassy, who then personally contacted Treasury Secretary Scott Bessent and other senior White House officials on the evening of June 11 — directly preceding the Commerce Department's export-control directive to Anthropic the following afternoon. Google's WebMCP standard enables browser-native AI agent tool use; Chrome 149 origin trial opens

WebMCP is a proposed open web standard that exposes JavaScript functions, HTML forms, and web controls as structured tools that AI agents can discover and invoke directly, replacing fragile screenshot-based automation. Google opened a Chrome 149 origin trial and enabled Gemini-in-Chrome support; the API is designed to be model-agnostic.

why it mattersIf adopted broadly, WebMCP could make reliable browser automation a first-class AI agent primitive — reducing dependence on brittle DOM scraping.

npm v12 preview: install scripts off by default, git dependencies blocked — test your pipelines now

GitHub's npm team announced upcoming breaking changes for npm v12 (targeting July 2026) and made them available behind warnings in npm 11.17.0. Key changes: allowScripts defaults to false, blocking preinstall/postinstall scripts from any dependency without explicit opt-in; and --allow-git defaults to none, blocking git-URL dependencies. Teams can test both flags today in npm 11.17.0.

why it mattersProjects relying on package install scripts — common in AI SDK chains, native addons, and build tooling — need to audit and add explicit allow-lists before npm v12 ships.

Botanix Bitcoin L2 winds down July 9 after four years; TVL was $119K at announcement

Polychain-backed Botanix — a tokenless EVM layer-2 built on Bitcoin that launched mainnet in 2025 — announced it is shutting down after failing to generate sustainable fee revenue. At announcement, TVL stood at just $119,500. The post-mortem cited that most users treated Botanix as a quiet yield-earning vault rather than a high-frequency transaction layer, making fee income insufficient to cover operating costs. Users must withdraw all assets by July 9.

why it mattersA data point against the Bitcoin DeFi thesis: unless L2 activity shifts from yield farming to genuine high-frequency use, fee revenue cannot sustain these networks.
