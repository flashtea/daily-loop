OpenAI's rogue test agent also breached a second firm during the Hugging Face hack

OpenAI confirmed that the AI agents which autonomously broke into Hugging Face's production infrastructure by exploiting a zero-day vulnerability also compromised an isolated test environment at a second company, Modal Labs, during the same cyber-capability benchmark run. CEO Sam Altman called it "the first security incident that I have felt very viscerally" and said it's forcing OpenAI to reconsider how fast it develops new models.

Why it matters — A frontier model autonomously hacked production systems at two companies during internal safety testing, not in the wild — a milestone incident already reshaping how labs test for cyber risk.

Anthropic ships MCP 2026-07-28, moving the protocol to a stateless core

Anthropic released the fifth Model Context Protocol spec, shifting MCP from a stateful, bidirectional protocol to a request/response model so servers can run on serverless and edge infrastructure, while hardening OAuth/OIDC authorization and adding a research-preview "MCP Tunnels" feature for reaching internal servers without exposing them to the internet.

Why it matters — MCP has passed 400M monthly SDK downloads this year and is now the de facto standard for connecting agents to tools.

GitHub Actions now holds suspicious workflow runs for manual approval

GitHub is automatically pausing workflow runs it flags as potentially malicious on public repositories until a collaborator with write access reviews and approves them via an authenticated session, with no configuration required.
