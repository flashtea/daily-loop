Apiiro found 1,379 secrets in 1,122 public copies of Claude Code's settings.local.json, the file where 'Yes, and don't ask again' saves approved shell commands word for word

The security firm scanned 104,185 public copies of .claude/settings.local.json on GitHub and found that 1,122 of them, about 1.1%, hold at least one credential, including 379 database passwords, 43 SSH logins to public servers, 42 GitHub, GitLab and npm tokens and 23 AWS keys; with git history, committed settings.json files and forks included, it counted 2,539 secrets across 1,994 repositories. Claude Code excludes the file only in the machine's global git excludes, not the project's .gitignore, so other clones and teammates are unprotected, and Gitleaks and TruffleHog both missed 215 of the files because the passwords sit inside commands such as PGPASSWORD= and sshpass -p; Apiiro says the four related bug reports since August 2025 were all closed by a bot without a reply.

why it mattersSearch every repository you have used Claude Code in for a committed .claude/settings.local.json or settings.json, including history, rotate anything found there before deleting it, and approve command patterns rather than one-off commands that carry a credential.
