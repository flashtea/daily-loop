The EU adopted sanctions on 1,569 people and companies in Russia's military-industrial complex, its largest single package of listings

The Foreign Affairs Council listed 826 Russian companies and 743 of their chief executives, more than half of them on the production chain for ballistic missiles, under an asset freeze and travel ban; the measures cover suppliers of semiconductors, microcircuits, radar, navigation equipment and explosives, and bring total listings under the Ukraine regime to close to 4,600.

why it mattersThe EU is now going after component suppliers rather than whole sectors, so anyone exporting electronics or dual-use parts eastward has 826 more companies to screen against.

AI for Software Development2 stories, lead above

OpenCode 2.0 moved the 212,000-star open-source coding agent onto one shared local service and broke 1.0 plugins

The terminal, desktop and web apps now attach to a single background service, so a session begun in the terminal continues in the other clients; the release rebuilt the API, added an embeddable SDK, let subagents and shell commands run in the background, and made Code Mode (the agent writes JavaScript that calls several MCP tools in one execution) the default for MCP servers. Plugins and server integrations built for 1.0 must be updated, and upgrades are now manual via `opencode upgrade --major`.

why it mattersIf you run OpenCode, stay on 1.x until your plugins are ported; if you do not, Code Mode is the first mainstream agent to batch MCP calls through generated code, a pattern worth copying for tool-heavy workflows.

The Kospi fell as much as 7.4% to 5,914, its lowest since late July, after China's CXMT said it would launch next-generation server DRAM this year

Samsung Electronics dropped 7.7% and SK hynix 8.8% as foreign investors sold heavily on reports that ChangXin Memory Technologies would ship DDR5 server memory by year-end; the Korea Exchange triggered its first sell-side sidecar since 19 August. The index has fallen five sessions in a row from 7,003.74 on 2 October, and the Nikkei lost 2.5% with Tokyo Electron down 6.6% and SoftBank 8%.

why it mattersKorea is the most concentrated public bet on the memory-chip cycle, and a credible Chinese entrant into server DRAM is the first thing in months to dent the AI-capex trade; watch Micron and the memory names, not just Nvidia.
