Anthropic Ships Claude Opus 5.5, Now the Default Model in Claude Code

Anthropic released Claude Opus 5.5, the first model in its 5.5 family, cutting typical workload costs by about 40% versus Opus 5 while boosting output speed over 30%. It's now the default model in Claude Code with a 1M-token context window; an early tester used it to audit and fix a 200,000-line codebase in under three hours, versus over 20 hours for Opus 5.

why it mattersA sharp jump in cost and speed changes the economics of long-running coding agents, not just their benchmark scores.

OpenAI Launches GPT-6 Sol and Luna, Roughly Halving API Prices

OpenAI expanded its GPT-6 family with Sol, built for coding and agentic tasks, and Luna, a lightweight model for high-volume clerical work, cutting API prices by about half versus their GPT-5.6 predecessors. Both are rolling out now in Codex, the API, and ChatGPT, with OpenAI claiming Sol makes about half as many mistakes as its predecessor at Astra-level reliability.

why it mattersA coding-tuned model at half the price directly undercuts rivals' agentic-coding pricing a day after Anthropic's own cost cut.
