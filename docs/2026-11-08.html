AI

A Claude Code user reported that the tool wrote their account email address into the User-Agent header of web requests it made; Anthropic's 2.1.317 release added a check before any call sends the email

The report, filed on 5 November against version 2.1.318 and one of the most-reacted issues in the anthropics/claude-code repository, says the address reached third-party sites during web searches and was followed by dozens of scam emails a day. Anthropic's changelog for 2.1.317, released on 3 November, added a check that asks before a web or shell tool call sends the account email to the network, and a contributor on the thread said it ships as a built-in plugin, on by default, that can be disabled from /plugins; the thread does not confirm that every path is covered.

why it mattersUpdate Claude Code to 2.1.317 or later, leave the privacy check on, and assume that sites you had the agent fetch while signed in may hold the email on your Anthropic account.
