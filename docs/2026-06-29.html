npm v12 Ships in July: Install Scripts Blocked by Default, Breaking Most CI Pipelines

npm v12, due July 2026, defaults allowScripts to off, blocks git dependencies, and blocks remote-URL tarball dependencies — all three require explicit opt-in. why it mattersMost Node.js CI pipelines need explicit config updates before v12 ships; teams using native addons (node-gyp) or git-sourced packages must act before July.
