Anthropic Says It Disrupted Claude Misuse Attempts Tied to Bio-Weapons Research and State-Backed Cyber Ops

Anthropic's September threat intelligence report details operations it detected and shut down between December 2025 and August 2026 across seven harm categories — including a case that could have supported biological weapons development, plus state-sponsored cyberattacks, surveillance, and influence operations — saying every disclosed operation was disrupted before causing harm.

Why it matters — The most detailed public accounting yet of how a frontier lab is catching real-world catastrophic-risk misuse of its own models.

Cognition Launches SWE-2, Claims Near-Frontier Coding at a Quarter of the Cost

Cognition released SWE-2 for Devin Desktop, CLI, Web, and Fusion, saying the model — post-trained from Kimi K33 — scores within a point of Claude Fable 5.1 on real-world coding benchmarks while costing up to 70% less to run, and comes within a few points of GPT-6 Astra at roughly a quarter of its price.

Why it matters — A serious price/performance challenge to the frontier labs' coding models from the maker of Devin and Windsurf.

OpenAI Opens Its Codex Agent Harness to Developers via a New Agents API

OpenAI launched a public beta of the Agents API, exposing the same session, orchestration, sandboxing, and context-compaction infrastructure that powers Codex so developers can build custom coding and computer-use agents by supplying only tools and instructions.

Why it matters — Turns OpenAI's internal agent harness into reusable infrastructure, competing directly with Claude's Agent SDK and similar Anthropic tooling.

Shopify Ditches React Native for Native Swift and Kotlin, Crediting Coding Agents

Shopify Engineering said it is moving its mobile apps back to native Swift and Kotlin after six years on React Native, having used AI coding agents to port the Shop app from React Native to SwiftUI in about 12 weeks — work that previously would have been prohibitively expensive to duplicate across platforms.

Why it matters — A concrete, large-scale example of coding agents changing a major engineering org's build-vs-share calculus, not just speeding up existing workflows.

Why it matters — Formalizes years of growing Rust investment at Microsoft (Azure, Windows) into an official internal standard.

Forgejo Patches Critical Remote-Code-Execution Flaw in Template Repositories

Forgejo shipped 16.0.4 and 15.0.8 to fix a critical vulnerability where a malicious template repository could smuggle in a .git folder during repo generation, letting an attacker read arbitrary data from and execute code on the Forgejo host; versions 16.0.3 and earlier are affected.

Why it matters — Self-hosted Git forges are a popular GitHub alternative; unpatched instances are remotely exploitable.
