Dev Tools & Releases

GitHub Actions workflow execution protections reach general availability

Owners can allowlist who may trigger workflows and which events can start them, scoped to specific workflow files, with audit insights and a REST API. Public repositories now default to having pull_request_target disabled.

Why it matters — A direct hardening step against CI supply-chain attacks.

GitHub adds proof of presence for high-impact actions

Enterprise members must re-authenticate or pass a multi-factor challenge before sensitive actions. It is currently available for managed-user enterprises using Microsoft Entra ID.

Why it matters — Limits the blast radius of stolen credentials in enterprise orgs.
