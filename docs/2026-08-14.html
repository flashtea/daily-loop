Anthropic in talks to buy video-AI startup Decart for $6B

Anthropic is negotiating to acquire Israeli startup Decart, which builds real-time generative-video models and GPU/chip-optimization software, in a deal valued around $6B, according to Bloomberg. It would be Anthropic's largest acquisition to date and comes three months after Decart was valued at $4B.

Why it matters — Decart's chip-optimization tech is aimed at squeezing more throughput from Anthropic's existing compute as demand for Claude keeps outrunning capacity.

GitHub's Agent Plugins 1.0 goes GA, backed by AWS, Microsoft, OpenAI, Vercel and Google

Agent Plugins 1.0, an open standard for packaging agent skills and MCP servers into a single installable, vendor-independent plugin, is now generally available in VS Code, Copilot CLI, the Copilot SDK and the Copilot app. GitHub published the spec on August 6 with AWS, Anysphere, Microsoft, OpenAI and Vercel; Google joined as a core maintainer the same day.

Why it matters — A shared plugin format means a skill-plus-MCP-server bundle can now ship once instead of needing a separate manifest and layout for every agent client.

VS Code 1.133 lets Claude sessions switch providers mid-conversation

The August VS Code release lets a Claude-powered agent session switch between a Copilot subscription and a direct Anthropic API key between turns without reconfiguring the agent host, adds chat sticky scroll to keep long conversations anchored, and reloads local HTML previews automatically on save.

Why it matters — Removes a rigid lock-in point for teams mixing Copilot seats with direct Anthropic billing on the same editor.

SEC abruptly postpones vote on proposed 'Regulation Crypto' rule

The SEC canceled Friday's open meeting at which it planned to propose 'Regulation Crypto,' a rule creating a registration-free capital-raising path for crypto firms, citing an 'unforeseen scheduling issue.' No new date has been set.

Why it matters — Chair Paul Atkins had made Reg Crypto a centerpiece of his deregulatory agenda; an unexplained last-minute pull adds fresh uncertainty to the timeline.

Goldman Sachs to buy NEOS Investments for up to $2.25B, landing a $1B bitcoin income ETF

Goldman Sachs agreed to acquire NEOS Investments, manager of the roughly $1.1B BTCI bitcoin synthetic-yield ETF, in a cash-and-equity deal valuing NEOS at up to $2.25B, with closing expected in early 2027 pending regulatory approval.
