Agent Plugins 1.0, an open standard for packaging agent skills and MCP servers into a single installable, vendor-independent plugin, is now generally available in VS Code, Copilot CLI, the Copilot SDK and the Copilot app. GitHub published the spec on August 6 with AWS, Anysphere, Microsoft, OpenAI and Vercel; Google joined as a core maintainer the same day.
