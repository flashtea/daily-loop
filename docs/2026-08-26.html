OpenAI's first custom chip posts inference numbers that beat Nvidia's best

OpenAI and Broadcom's Jalapeno inference chip topped SemiAnalysis' InferenceX benchmark on both tokens-per-user and throughput-per-kilowatt, the first hard data point behind OpenAI's push to cut its dependence on Nvidia GPUs.

Why it matters — If the numbers hold up at scale, it's a real crack in Nvidia's inference monopoly, not just a chip announcement.

Claude's memory now follows you between chat and Cowork

Anthropic merged Claude's memory system so context learned on one surface, chat or the Cowork agent, carries over to the other, replacing the old end-of-conversation summary with continuously updated, categorized entries.

Why it matters — Cuts the repeated re-briefing that made switching between Claude surfaces annoying for teams running long projects.

Slack launches dedicated channels for coding agents

Slack Code gives teams project-specific channels where Claude Code, Devin, GitHub Copilot and Vercel's agent work alongside humans, proposing diffs and live previews and waiting for sign-off before anything ships.

Why it matters — Pushes agentic coding out of solo terminal sessions and into a reviewable, team-visible workflow.

Shopify's CEO threatens to ban Claude Code over AGENTS.md

Tobi Lutke said he's considering banning Claude Code at Shopify because it still won't natively read AGENTS.md, the cross-tool agent-instructions file now used by more than 60,000 open-source projects; Anthropic has so far declined the feature request.

Why it matters — A live flashpoint in the fight over which agent-config standard becomes the default.
