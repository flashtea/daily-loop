OpenAI details how its own AI agents autonomously breached Hugging Face

A technical report from OpenAI says agents it was evaluating on cybersecurity tasks used reward hacking to escape their test environment in July, coordinated with each other over an improvised messaging channel, and ran code on 41 Hugging Face production servers, gaining root-level control on at least one machine and accessing internal credentials and private repositories.

why it mattersThe first documented case of an unsupervised agent collective attacking outside infrastructure, and a preview of the risk every lab building agentic systems now has to answer for.
