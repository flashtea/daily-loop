AI Research & Models

OpenAI says Astra is the first model to cross its "Critical" cyber-capability threshold

OpenAI disclosed that its unreleased Astra model meets the Preparedness Framework's Critical cybersecurity bar: in expert-led evaluations it built a full browser-sandbox-escape exploit chain and chained multiple OS vulnerabilities into a local-to-root privilege escalation, without a human directing each step. Its most advanced cyber capabilities will initially be limited to vetted testers.

Why it matters — The first model OpenAI has ever rated capable of finding and chaining zero-days largely on its own — a marker of how offense-capable frontier models have become.

AI for Software Development

"GitSpawn" flaw lets malicious repos silently run code in Claude Code, Cursor, Codex and more

Manifold Security disclosed eight vulnerabilities across seven CLI coding agents, dubbed GitSpawn: a repo's own git configuration (via the core.fsmonitor hook) can execute attacker-controlled code the instant an agent runs a routine git status or diff — no prompt, no approval, sometimes before authentication. Claude Code and Cursor have shipped fixes; Hermes Agent, Qwen Code and Grok Build were still exploitable on Manifold's September 1 retest.

Why it matters — Opening an untrusted repo with any of these tools can hand over code execution before you've typed a single prompt.

AI Research & Models

Google ships Gemini 3.8 Flash and a cybersecurity-focused "Cyber" variant

Google released Gemini 3.8 Flash — its third Flash release in six weeks — alongside Gemini 3.8 Flash Cyber, a defender-oriented model that Chrome's security team says produced 2.6x more correct vulnerability patches than larger commercial models in internal testing. Both are priced the same as 3.7 Flash through the end of the year.

Why it matters — Google is now shipping roughly monthly, with defensive-security tooling emerging as its own model category.

VS Code 1.136 adds "Agent Merge" to autonomously clear PR feedback and conflicts

Visual Studio Code's September release lets an agent resolve review comments, fix failing checks and untangle merge conflicts until a pull request is ready to merge, plus experimental multi-root workspace support for running Copilot and Claude agent sessions across every folder in a workspace at once.

Why it matters — Pushes agentic coding further into the mechanics of actually shipping a PR, not just writing the diff.
