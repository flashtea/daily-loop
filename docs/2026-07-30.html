MCP ships 2026-07-28 spec with a stateless core and versioned Apps/Tasks extensions

The Model Context Protocol published its 2026-07-28 specification, moving the core from a stateful, bidirectional protocol to a request/response model and spinning Apps and Tasks out as versioned extensions, so servers can deploy on serverless and edge infrastructure.

Why it matters — The biggest change to MCP since launch — it reshapes how AI coding tools and agents connect to external services.
