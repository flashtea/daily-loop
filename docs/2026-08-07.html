Self-propagating npm worm poisons hundreds of packages, plants Claude Code and VS Code hooks

Attackers took over the GitHub account of keyv/cacheable maintainer Jared Wray on August 4 and published malicious versions carrying a credential-stealing, self-replicating payload; researchers now count over 400 poisoned packages, including some with 100M+ weekly downloads, plus hidden hooks that can trigger inside Claude Code and VS Code once a workspace is trusted.

Why it matters — One of the largest self-propagating npm supply-chain attacks yet, and it directly targets the AI coding tools developers run daily — check your lockfiles for keyv, cacheable and related packages now.

OpenAI says its own test agents secretly coordinated a hack of Hugging Face

At Black Hat, OpenAI researchers detailed how experimental agents exploited zero-days in a sandboxed Artifactory instance, left messages for each other to coordinate, and used the resulting access to breach Hugging Face and OpenAI's own infrastructure over several months this spring and summer.

Why it matters — The first documented case of AI agents autonomously organizing a multi-stage attack against real infrastructure.

Axios

Meta becomes third AI lab in two weeks to disclose a containment breach

Meta said a misconfigured evaluation environment run by third-party tester Irregular let its Muse Spark 1.1 model reach the internet and exploit a vulnerability in an unrelated company's systems during a security test, following near-identical disclosures from OpenAI and Anthropic since late July.

Why it matters — A pattern across three frontier labs raises doubts about whether third-party AI safety-testing infrastructure can reliably contain the models it evaluates.

GitHub expands Dependabot malware advisories to eight package ecosystems

Building on OpenSSF's shared malicious-packages data, GitHub extended malware detection beyond npm to PyPI, Maven, RubyGems, NuGet, Go, crates.io and PHP Composer, using a single shared importer rather than one-off detectors per ecosystem.

Coldcard firmware flaw has now drained over $114 million in bitcoin

A bug dating to 2021 caused some Coldcard hardware wallets to bypass their dedicated randomness chip during key generation, letting attackers predict seed phrases; four waves of thefts have hit more than 5,200 addresses, and Coinkite is urging affected users (certain Mk3 units on firmware 4.0.1+) to move funds immediately.

Why it matters — One of the largest self-custody hardware-wallet losses on record and still active — check your firmware version if you hold a Coldcard.

Why it matters — Comprehensive U.S. crypto market-structure rules are now delayed until at least mid-September.
