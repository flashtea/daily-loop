OpenAI's new cyber model finds real Chrome zero-days, crosses a safety threshold

OpenAI expanded its Daybreak security initiative and launched GPT-5.6-Cyber, which discovered two previously unknown V8 vulnerabilities that could be chained to corrupt memory and escape Chrome's sandbox; Google has patched them as CVE-2026-15903. OpenAI says it's the first model to hit the 'High' cyber capability threshold under its Preparedness Framework.

why it mattersOpenAI is making hardware security keys mandatory for all Daybreak accounts by September 1, a sign it sees real offensive risk in a model it's still rolling out.

Anthropic makes Claude Code's auto mode the default

Starting August 14, Claude Code will run in auto mode by default for Pro, Max, and Team plans, proceeding without per-step approval unless an action is judged irreversible, destructive, or aimed outside the user's environment.

why it mattersAnthropic says a study of 1,053 paid testers found auto mode caught 89% of harmful actions versus 13.6% for manual human review, the case it's making for flipping the default.
